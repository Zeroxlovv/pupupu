# 📚 Расписание и Рейтинг ВГУИТ

Веб-приложение для просмотра расписания и рейтинга студентов ВГУИТ. Работает полностью в браузере, без серверной части!

## ✨ Возможности

### 📅 Расписание
- Выбор группы при входе
- Просмотр расписания на неделю
- Фильтрация по дням недели
- Фильтрация по неделям (числитель/знаменатель)
- Добавление своих занятий
- Настройка даты начала числителя
- **Офлайн-режим** - расписание сохраняется в браузере
- **Автообновление** каждые 15 минут
- Индикатор онлайн/офлайн статуса
- Показывает время последнего обновления

### 📊 Рейтинг (пошаговая фильтрация)
- **Шаг 1**: Выбор факультета и группы
- **Шаг 2**: Выбор семестра и учебного года
- **Шаг 3**: Выбор предмета
- **Шаг 4**: Просмотр списка студентов с зачётками и рейтингом
- Цветовая индикация оценок
- Сортировка по рейтингу
- Кэширование данных (30 минут)

### ⚙️ Настройки
- Изменение даты начала числителя
- Включение демо-режима
- Добавление/редактирование своих занятий
- Сохранение всех настроек в localStorage

## 🚀 Быстрый старт

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build
```

Приложение будет доступно на http://localhost:3000

### Деплой на VPS

#### Способ 1: Docker (рекомендуется)

```bash
# Клонируйте проект на VPS
git clone <your-repo> timetable
cd timetable

# Запустите одной командой
docker-compose up -d
```

Готово! Откройте `http://your-vps-ip`.

#### Способ 2: Nginx (без Docker)

```bash
# Установите Nginx
sudo apt update
sudo apt install nginx

# Соберите приложение
npm install
npm run build

# Скопируйте файлы
sudo mkdir -p /var/www/timetable
sudo cp -r dist/* /var/www/timetable/
sudo chown -R www-www-data /var/www/timetable

# Настройте Nginx (используйте nginx.conf)
sudo nano /etc/nginx/sites-available/timetable
# Вставьте содержимое nginx.conf
sudo ln -s /etc/nginx/sites-available/timetable /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 📱 Android приложение

Полный проект Android Studio находится в папке `android-project/`.

### Особенности Android-версии
- Нативное приложение на Kotlin
- WebView с поддержкой всех функций
- Pull-to-refresh для обновления
- Тёмная тема
- Поддержка обеих вкладок (Расписание + Рейтинг)
- Офлайн-режим

### Сборка APK

1. Откройте `android-project/` в Android Studio
2. Скопируйте файлы из `dist/` в `app/src/main/assets/web/`
3. Build → Generate Signed Bundle / APK
4. APK будет в `app/release/`

## 🏗️ Архитектура

```
┌─────────────────┐
│   Браузер       │
│   (React App)   │
└────────┬────────┘
         │
         │ CORS-прокси
         ▼
┌─────────────────┐
│ allorigins.win  │
│ corsproxy.io    │
└────────┬────────┘
         │
    ┌────┴────┐
    │         │
    ▼         ▼
┌────────┐ ┌─────────────────┐
│timetable│ │ rating.vsuet.ru │
│.vsuet.ru│ │ (парсинг HTML)  │
└────────┘ └─────────────────┘
```

**Как это работает:**
1. Приложение делает запросы через CORS-прокси
2. Данные парсятся из HTML прямо в браузере
3. Результаты кэшируются в localStorage (30 минут)
4. Расписание автоматически обновляется каждые 15 минут
5. При отсутствии интернета используется кэш

## 📝 Особенности работы

### Офлайн-режим
- Расписание автоматически сохраняется в localStorage
- При отсутствии интернета показывается сохранённое расписание
- Индикатор показывает статус подключения
- Отображается время последнего обновления

### Автообновление
- Расписание обновляется автоматически каждые 15 минут
- Рейтинг кэшируется на 30 минут
- Кнопка обновления позволяет принудительно обновить данные

### CORS-прокси
Приложение использует публичные CORS-прокси:
- https://api.allorigins.win/
- https://corsproxy.io/

Если прокси недоступны, включите демо-режим в настройках.
